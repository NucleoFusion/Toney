# General

Keybinds in Toney follow the [bubbletea](https://charm.sh/bubbletea) nomenclature, that is,

|  Vim  | Toney |
|-------|-------|
|\<S-h\>|  "H"  |
|\<C-x\>|  "ctrl+x"  |
|\<M-x\>| NA|
|\<Space\>| " "|
|\<Up\>| "up"|

So always make sure the keybinds you input are supported by bubbletea. There is a way to have `alt` but it is not yet supported, it will be added in future versions, keep yourself updated!
