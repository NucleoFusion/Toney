# Global 

Denoted by the `[keybinds.global]` tag in TOML.

## Up 

can change the 'up' key, generally used for menu's etc using the `up` toml key.

default value is:
```toml
up = "up"
```

## Down 

can change the 'down' keybind, generally used for menu's etc using the `down` toml key.

default value is:
```toml
down = "down"
```
